# Hi, I'm Bogdan

Second-year Computer Science student at the **Polytechnic University of Bucharest** (Faculty of Automatic Control and Computers). I like building things from the ground up, from a neural network written in C to a web app a gymnastics coach uses every week.

**Open to software engineering internships and part-time roles** (hybrid in Bucharest, or remote).

## Projects

| Project | What it is | Stack |
|---|---|---|
| [Gym attendance tracker](https://github.com/bogdanilie2706-gif/gym-attendence-tracker) | Installable web app for a children's gymnastics class: attendance, payments, real-time sync, offline support. [Live demo](https://prezenta-gimna.web.app/?demo) | JavaScript, Firebase |
